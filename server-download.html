GET STARTED

Running your server

1

Download and run

Click the .exe download above and open it on your Windows PC. Leave its console window open while using the server.

2

Connect LuauForge

Open Shared Scripts or Feedback in the IDE and paste this local API origin:

http://127.0.0.1:8787
3

Create your workspace

Create a shared workspace, add scripts, and connect the Studio plugin. Data is saved under %LOCALAPPDATA%\LuauForgeServer.

Want to invite developers outside your PC?

The .exe starts a local-only HTTP server. Running it does not publish a public HTTPS endpoint. For remote invitations or Discord feedback on the public website, configure a trusted HTTPS reverse proxy/tunnel or deploy the Node backend to a host with persistent storage. Do not expose an unprotected HTTP port to the internet.

Discord posting is optional and off until you set a private DISCORD_BOT_TOKEN environment variable for the server process. Never put the token into the website.
